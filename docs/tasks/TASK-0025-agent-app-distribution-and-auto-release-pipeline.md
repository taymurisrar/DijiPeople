# TASK-0025 — Agent app distribution and auto-release pipeline

## Objective

Makes the desktop agent shippable and its releases automated. A persistent disk
gives published installers a durable home; the release CLI/CI can now build the
agent itself; a version bump on `develop` auto-builds and publishes to the BETA
channel; employees can self-download the installer and their agents can
auto-update; and code signing is a drop-in the moment a certificate is added.
Done when a version bump produces a published BETA release with no manual build,
an employee can download from Settings → Apps & Downloads, and the only remaining
steps are the owner's (production secrets, promotion, buying a cert).

Owner decisions (AskUserQuestion, 2026-08-26): Render persistent disk for
storage; ship unsigned now with signing wired for later; version-bump →
auto-publish BETA with manual STABLE promotion; any employee may self-download.
