# TASK-0027 — Tenant app assignment: which tenants receive a release

## Objective

Give platform admins the control that decides **which tenants receive the
desktop agent**, and on **which release channel** their agents auto-update —
the missing "who gets it" half of the distribution pipeline (TASK-0025 built
the pipeline, TASK-0026 the "what exists on a channel" releases UI). A tenant
assigned to STABLE receives the latest STABLE release, one on BETA the latest
BETA, and a disabled/unassigned tenant none. Done when a platform admin can, in
the admin app, enable/disable the agent per tenant and set its channel, backed
by audited, platform-guarded API endpoints over `TenantAppAssignment` — without
ever building or promoting a release.
