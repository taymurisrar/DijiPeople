## Objective

Gives the platform admin app a releases screen (Operations -> App releases): every published version by channel and status, with enable/disable and one-click channel promotion (INTERNAL -> BETA -> STABLE). Backed by two new user-session endpoints (GET /app-releases/manage, POST /app-releases/:id/promote, both appDownloads.manage, audited). Promotion reuses the source storage key so the promoted channel ships the byte-for-byte tested artefact. Answers "is versioning done on the admin app".
