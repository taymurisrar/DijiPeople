# ITEM-0245 — Recruitment settings are NOT_IMPLEMENTED (28 keys) and hire starts no onboarding

## Summary

`tenant-settings-dispositions.ts` marks ~28 recruitment settings NOT_IMPLEMENTED (default onboarding plan, template ids, offer approval, hire notifications, auto-activation). Hiring creates a draft employee but starts no onboarding. DP-MASTER/WP-05.S1, WP-07, WP-08.

## Why It Matters

Administrators can configure behaviour that never happens.

## Evidence

`services/api/src/modules/tenant-settings/tenant-settings-dispositions.ts:233-265`; no readers for `defaultOnboardingPlanId` and the template-id keys outside the catalog.

## Proposed Approach

Each setting gets a real reader or is hidden/marked unavailable (WP-05 AC). Needs an ExecPlan alongside WP-07/08.

## Acceptance Criteria

Every recruitment setting is either read by code under test or disabled in the UI with a reason.
