# ITEM-0212 — Public signup offers no promotion code field for Safepay-routed buyers

## Summary

The tenant plans screen takes a promotion code and the server applies it for Safepay. The public subscribe wizard has no code field: Stripe buyers enter codes on Stripe's own page, Safepay buyers have nowhere to.

## Why It Matters

A campaign code cannot be used by a new PKR customer signing up on the website.

## Evidence

`SubscriptionOrderService.openOrder` (discount fixed at zero); `apps/landing/app/subscribe/subscribe-form.tsx`.

## Proposed Approach

Accept an optional code on `PublicSubscribeDto`, evaluate it with `evaluatePromotion` in `openOrder` for non-Stripe orders, and store `promotionId`/`discountAmount` on the order; redeem on payment in `recordOrderPayment`.

## Acceptance Criteria

- A valid code reduces a PKR order total server-side.
- An invalid code is refused with `BILLING_PROMOTION_INVALID`.

## Dependencies

None.
