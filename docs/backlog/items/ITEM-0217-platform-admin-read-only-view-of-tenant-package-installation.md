# ITEM-0217 — Platform admin read-only view of tenant package installations

## Summary

Platform administrators should see, read-only, which packages and versions each tenant has installed and which imports failed.

## Why It Matters

Support cannot see a tenant's package state without asking the tenant.

## Evidence

Owner decision D-3 (2026-09-26). The data exists: CustomizationPackageOperation and CustomizationSolution per tenant.

## Proposed Approach

A platform-guarded read endpoint in super-admin and an admin page; no cross-tenant mutation.

## Acceptance Criteria

A platform admin sees installations and failures per tenant; nothing can be changed from there.

None.
