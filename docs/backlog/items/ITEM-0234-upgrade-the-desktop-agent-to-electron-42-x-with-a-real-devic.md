# ITEM-0234 — Upgrade the desktop agent to Electron 42.x with a real-device verification

## Summary

`apps/agent-desktop` pins `electron@39.8.10` after SESSION-0137 WP1, which clears every Electron advisory that has a 39.x backport. Five Dependabot alerts (96, 98, 100, 102, 152 and their lockfile twins) are fixed only in 41.10.x / 42.11.16, so they stay open until the agent moves to Electron 42.11.16. The same upgrade also removes the unfixable `extract-zip` advisories (GHSA-7pqw-9j4j-h8q3, GHSA-jmr9-qjv8-65gv) from the dependency tree, because Electron 42 no longer depends on it.

## Why It Matters

The agent ships to employees' machines, so an Electron advisory is a vulnerability in software running on a device the product does not control. The four 41.10.x advisories are not reachable today: the agent loads only local files, with no `webview`, `window.open`, custom protocol or remote content (`src/main/main.ts`, three `loadFile` calls). GHSA for the eMudhra intermediate certificate mitigation (alert 152, fixed in 42.11.16) affects Chromium's trust store and so applies to the agent's HTTPS calls to the API. It is low practical risk, but it is the one that cannot be argued away by call-site evidence.

## Evidence

- Alert inventory and fixed-in versions: GitHub Dependabot alerts 96, 98, 100, 102, 152 (retrieved 2026-11-21).
- No remote content: `apps/agent-desktop/src/main/main.ts` lines 141, 466, 513 use `loadFile` only; grep for `webview|window.open|setWindowOpenHandler|registerSchemeAsPrivileged|protocol.` finds nothing in `src`.
- Dependabot PRs #116 and #117 propose the same bump but have not been run against a device.

## Proposed Approach

Needs a plan before merge, because the agent's Electron-dependent modules (`secure-store`, `tray`, `main`, `session-manager`, `update-manager`) have no automated harness (see `apps/agent-desktop/AGENTS.md`). Steps: bump to 42.11.16 exactly, rebuild the native modules (`keytar`, `active-win`), run `check-types`, `test` and `dist:win`, then verify on a real Windows device: sign-in, vault round-trip, window-title and clipboard capture, location capture, tray, auto-update. Decide whether to publish through the existing app-release process.

## Acceptance Criteria

- `apps/agent-desktop/package.json` pins `electron` at or above 42.11.16.
- `npm audit` reports no Electron or `extract-zip` advisory.
- `npm --workspace agent-desktop run check-types`, `test` and `build` pass.
- A written real-device checklist (sign-in, secure-store, capture, tray, update) is run on Windows and its result recorded.
- Dependabot PRs #116 and #117 are closed as superseded.
