# ITEM-0218 — Carry module views, navigation, workflows and reports in customization packages

## Summary

Package format 1 carries modules, fields, forms, views, choice lists, relationships, action bars, widgets and environment variables. Saved module views (ModuleView), navigation overrides, workflows, report definitions and templates live outside the package model and do not travel.

## Why It Matters

A tenant that customizes dashboards or reports still rebuilds them in each environment.

## Evidence

TASK-0033 discovery: none of those models is linked to CustomizationSolution; Workflow has no stable key (unique on name only).

## Proposed Approach

Add each as a portable component type in turn, starting with report definitions (already keyed) and ModuleView (keyed by slug). Workflows first need a stable key.

## Acceptance Criteria

Each added type round-trips DEV → UAT through the existing import engine.

## Dependencies

None.
