# ITEM-0228 — Onboarding and activation links are stored verbatim in PlatformOutboundEmail.htmlBody for retries

## Summary

Partner onboarding and partner portal activation emails carry a live bearer link. `PlatformOutboundEmail.htmlBody` stores the rendered HTML verbatim so that the retry worker can resend it. Anyone with database access, or with an admin screen that shows outbound email bodies, can therefore read valid links. The dev console provider also logs them.

## Why It Matters

A link that is still valid grants onboarding or portal activation for the partner.

## Evidence

TASK-0037 WP-05 (BUG-3981) kept this behaviour because retries need the body. Activation emails have the same exposure.

## Proposed Approach

Store a template reference plus non-secret variables, and rebuild the link at send time from a token re-issued at retry. Alternatively, encrypt the stored body with `SecretEncryptionService` and redact it in admin views. Either needs a short ExecPlan.

## Acceptance Criteria

No live link is stored in plaintext or logged, and retries still deliver a working link.

None.
