# ITEM-0219 — Package CLI and a CI pipeline step for validate, export and import

## Summary

Validate, export and import are API operations today (release-readiness, versions/:version/artifact, package-imports/analyze and execute). A CLI and a CI step would let a package move DEV → UAT → PROD from a pipeline.

## Why It Matters

Promotion is manual and browser-driven.

## Evidence

EXECPLAN-0052: the engine is browser-independent by design; operations are persisted and resumable.

## Proposed Approach

A small node CLI over the existing endpoints with a service-account token; a CI job that imports the artifact committed to the repo into UAT.

## Acceptance Criteria

A pipeline imports a committed .djpkg into a target workspace and fails on a blocked plan.

## Dependencies

Service-account authentication for tenant APIs.
