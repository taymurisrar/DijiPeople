# ITEM-0075 — The subscribe wizard never collects companySize, which the API and Customers module both expect

## Summary

`CustomerAccount.companySize` is a column the Customers module displays, the
sales-assisted conversion path populates from the lead, `PublicSubscribeDto`
accepts, and `buildOrganizationProfile` maps. The one thing that never supplies
it is the subscribe wizard, so on every self-service customer it is null.

## Why It Matters

Small on its own. Worth recording because it is the residue of [[BUG-0280]]: the
plumbing is complete end to end and only the first step is missing, which is
exactly the shape that looks implemented from any single file. The next person
reading `PublicSubscribeDto` will reasonably assume the field arrives.

It also has a real use — segmenting self-service customers by size is how you
decide which of them a salesperson should call.

## Evidence

- `apps/landing/lib/onboarding-wizard.ts`, `buildSubmitPayload` — sends
  `industry` and `estimatedEmployeeCount`, not `companySize`.
- `services/api/src/modules/billing/dto/public-subscribe.dto.ts` — declares
  `companySize?: string`.
- `services/api/src/modules/billing/services/billing.service.ts:375` — maps it
  into the organization profile.
- `services/api/src/modules/billing/services/subscription-order.service.ts`,
  `buildOrganizationProfile` — writes it when present.

## Proposed Approach

Two defensible answers, and the choice is a product one:

1. **Collect it.** Add a band select to the wizard's organization step, using
   the same values the lead form offers so the two funnels are comparable.
   Costs one more field on a form that is already long.
2. **Derive it.** `estimatedEmployeeCount` is already collected; map it to a
   band server-side and stop asking a question whose answer is implied. Costs
   nothing at the form and makes the two columns consistent by construction.

Option 2 is the recommendation — the wizard already asks the more precise
question, and asking both invites them to disagree.

## Acceptance Criteria

- A self-service customer record carries a `companySize` consistent with its
  `estimatedEmployeeCount`, or the column is removed from the self-service
  expectation entirely and documented as sales-assisted only.
