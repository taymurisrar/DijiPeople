# QA-TENANT-068 — Employee responses never carry login secrets and load for MFA-enrolled users

## Preconditions

A tenant user who has signed in with MFA, plus a second employee whose account has never used MFA, and a caller with employee read permission.

## Steps

1. Automated: in services/api, run `npx jest src/modules/employees/employee-user-summary.spec.ts`.
2. Production: as the MFA-enrolled user, open My Profile.
3. Request `GET /api/employees/<id>` for both employees and inspect the `user` object.

## Expected Result

- The spec passes all 4 cases.
- My Profile loads.
- `user` contains only id, email, firstName, lastName, status, lastLoginAt and roles. It has no passwordHash and no mfa* field.
