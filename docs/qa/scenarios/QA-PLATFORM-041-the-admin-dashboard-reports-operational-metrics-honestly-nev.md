# QA-PLATFORM-041 — The admin dashboard reports operational metrics honestly, never a fabricated zero

## Preconditions

The `platform-administration` dashboard view; a way to force one section's
underlying query to reject (e.g. `partner.groupBy`).

## Steps

1. Load the dashboard normally; check for a login/failed-login metric, an MFA
   adoption metric, an error-rate trend and a job/queue-failure-rate tile.
2. Force the `partner.groupBy` query to reject; reload the dashboard.
3. Force a contract-generation-failure source to be genuinely unavailable.
4. Repeat step 3 for the admin-side `apps/admin/lib/dashboard/operations-dashboard-metrics.ts` rendering of that section.

## Expected Result

Step 1 shows all four new metric categories with real data. Step 2 still
resolves the whole dashboard — `result.partners.available === false` with the
rejection's message as `reason`, while platform/users/agreements/operational
all resolve normally (one failing section never blanks the other four). Steps
3-4 report `{ available: false, reason: ... }` / `"Not available"`, never a
`0` or `{ value: 0 }`.
