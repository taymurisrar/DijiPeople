# QA-AGENT-005 — The desktop agent re-sends a failed heartbeat batch exactly once, in order

## Preconditions

A checkout of the repository. No Electron runtime is needed.

## Steps

1. `npm --workspace agent-desktop run test -- offline-queue`.
2. Adversarial form: make `drain` non-destructive, or `prepend` append, and
   re-run.

## Expected Result

Step 1 passes. Step 2 fails by name — "removes what it drained" for the first, the ordering assertion for the second.

The contract: a drained batch is gone so a successful send cannot re-send it;
a returned batch is re-sent exactly once and lands **in front of** anything
queued since; the bound drops the oldest; and a malformed event never reaches
the wire.
