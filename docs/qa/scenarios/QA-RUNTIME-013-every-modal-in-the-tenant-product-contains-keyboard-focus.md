# QA-RUNTIME-013 — Every modal in the tenant product contains keyboard focus

## Preconditions

A checkout of the repository, and a browser for the manual half.

## Steps

1. `npm run check:dialogs-contained`.
2. `npm --workspace web run lint` — `jsx-a11y` runs as errors.
3. Manual form: open any modal, press Tab repeatedly, then press Escape.

## Expected Result

Steps 1 and 2 pass. In step 3 focus **cycles inside the dialog** and never
reaches the page behind it; Escape closes the dialog; and focus returns to the
control that opened it.

A screen reader announces it as a dialog with the name shown in its heading.
A modal overlay that uses neither `<Dialog>` nor `useDialogBehavior` fails
step 1 by path.
