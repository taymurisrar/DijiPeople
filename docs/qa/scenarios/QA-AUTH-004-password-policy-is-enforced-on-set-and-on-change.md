# QA-AUTH-004 — Password policy is enforced on set and on change

## Preconditions

Tenant password policy configured through the settings runtime.

## Steps

1. Set a password below each configured bound in turn.
2. Set one that satisfies every rule.
3. Change an existing password to one that violates a rule.

## Expected Result

Each violation is rejected with a field-level error, and the same rules apply on change as on initial set.

## Notes

Policy is tenant-configurable, so the scenario asserts the rule that is configured — never a hardcoded length.
