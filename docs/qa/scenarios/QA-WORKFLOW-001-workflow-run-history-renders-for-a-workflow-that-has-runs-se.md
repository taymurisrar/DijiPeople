# QA-WORKFLOW-001 — Workflow run history renders for a workflow that has runs (server component boundary)

## Preconditions

A tenant with a tenant administrator, a workflow with one active action, and at
least one run of that workflow (here a PARTIALLY_FAILED run).

## Steps

1. Sign in as the tenant administrator.
2. Open Settings, Approvals and Workflows, Workflows, and open the workflow.
3. Scroll to Run History.

## Expected Result

The page renders. The Run History table lists each run with its start time, a
result badge that reads "PARTIALLY FAILED" for a half-delivered run, the number
of emails sent and the failure detail. No error page is shown.

## Notes

Created 2026-11-25 at `709578f5`. Run in a real browser on 2026-11-25 against an
isolated API and web stack: before the fix the page showed the error boundary
("Attempted to call formatDateTime() from the server"); after it the table and
the PARTIALLY FAILED badge render. The automated half pins the cause (the
formatter must not come from a client module); the render itself is browser-only.
