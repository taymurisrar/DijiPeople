# QA-REPORTING-003 — Reporting headcount excludes soft-deleted employees

## Preconditions

A tenant with at least one soft-deleted employee.

## Steps

1. Read headcount through the reporting engine.
2. Compare it with the count on the Employees screen.
3. Inspect the `workforce` data source's `baseWhere`.

## Expected Result

The two counts agree. `baseWhere` carries both `isDeleted: false` and `deletedAt: null`, and the predicate survives into the composed `where` rather than only being declared.

## Notes

Soft delete is not universal in this schema, which is why it gets forgotten. The predicate lives in the shared data source so every metric, breakdown, report and export inherits it and opting out has to be deliberate.
