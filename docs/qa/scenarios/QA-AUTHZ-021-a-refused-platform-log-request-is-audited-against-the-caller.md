# QA-AUTHZ-021 — A refused platform log request is audited against the caller and cannot end the API process

## Preconditions

An isolated database with a tenant whose user holds the Global Administrator role.

## Steps

1. As that tenant user, call `GET /api/platform/logs` with the web client.
2. Wait about 750 ms for any discarded promise to reject.
3. Read the audit log for the tenant.

The response is 403. No unhandled rejection is raised. The tenant's audit log contains PLATFORM_ERROR_LOG_ACCESS_DENIED with that user as actor.
