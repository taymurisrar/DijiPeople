# QA-BILLING-043 — A Safepay checkout is priced on the server and a fixed coupon never crosses currencies

## Preconditions

A tenant with no live subscription and a published PKR per-seat price, and promotions of each kind.

## Steps

1. Check out 5 seats with no code.
2. With a 20% code.
3. With a fixed USD code on the PKR price.
4. With an unknown code.
5. Repeat the identical checkout.
6. Check out while the subscription is ACTIVE.
7. Read the payment as another tenant.

## Expected Result

- The provider is asked for the server-computed total (`25000.00`, then `20000.00` with 20% off); the browser never sends an amount.
- A fixed code in another currency and an unknown code are refused before any provider call.
- A repeat returns the same checkout without opening a second.
- An ACTIVE subscription is refused with 409.
- Another tenant gets `PAYMENT_NOT_FOUND`.
