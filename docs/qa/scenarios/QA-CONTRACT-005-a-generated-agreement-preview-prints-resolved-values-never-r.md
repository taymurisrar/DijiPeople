# QA-CONTRACT-005 — A generated agreement preview prints resolved values, never raw placeholders

## Preconditions

A draft `PARTNER_AGREEMENT` with `platform.legalName`/`partner.name` stored;
the same agreement after signing.

## Steps

1. `POST /contracts/:id/generate/pdf` on the draft agreement; extract the PDF
   text.
2. `POST /contracts/:id/generate/docx`; extract the DOCX text.
3. Open the document-fields view for the same agreement.
4. Rename the partner, then regenerate/view the already-signed copy.
5. Leave a required placeholder unresolved in a draft preview; leave an
   optional one unresolved.

## Expected Result

Steps 1-2 print "DijiPeople Technologies Ltd." and "Northstar Advisory" (or
equivalent resolved values), with no `{{` anywhere and signature lines reading
"Pending". Step 3 renders through the same function as steps 1-2. Step 4's
renamed partner does not change the already-executed copy — it renders from
the frozen version and evidence, not current values. Step 5's required token
stays visibly marked; the optional one follows its configured empty fallback.
