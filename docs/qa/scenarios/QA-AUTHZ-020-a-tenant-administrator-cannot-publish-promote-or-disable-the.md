# QA-AUTHZ-020 — A tenant administrator cannot publish, promote or disable the global desktop agent releases

## Preconditions

An isolated database with a tenant whose user holds the Global Administrator role, a platform super admin, and one global `ApplicationRelease` on the BETA channel.

## Steps

1. As the platform super admin, disable then enable the release (control).
2. As the tenant administrator, read `GET /app-releases` (control).
3. As the tenant administrator, call `POST /app-releases/:id/disable`.
4. As the tenant administrator, call `POST /app-releases/:id/promote` with channel STABLE.
5. As the tenant administrator, call `POST /app-releases` with an external URL.
6. As the tenant administrator, call `GET /app-releases/manage`.

## Expected Result

Steps 1 and 2 succeed. Steps 3 to 6 each answer 403, the release stays active, no STABLE copy exists and no row was added.
