# QA-RUNTIME-047 — Custom module delete: impact dialog, own metadata cascades, cross-module reference blocks

## Preconditions

Tenant admin with customization.tables.update; a custom module with one main form, and a second custom module with a lookup field targeting the first.

## Steps

1. Settings > Customization > Modules, open Delete on the referenced module.
2. Confirm the dialog lists the dependent lookup field and the Delete button is disabled.
3. Remove the lookup field, reopen Delete on the first module.
4. Confirm the dialog lists fields, forms, views, records and package components, then delete.

## Expected Result

The referenced module is blocked and names the referencing field. After the reference is removed the module is deleted with its forms, fields, views and records, and no loop message appears.
