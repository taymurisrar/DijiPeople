# QA-AGENT-006 — A partial agent config cannot silently disable or widen what is captured

## Preconditions

A checkout of the repository.

## Steps

1. `npm --workspace agent-desktop run test -- config-manager`.
2. Adversarial form: let `allowScreenshots` follow the server response, and
   re-run.

## Expected Result

Step 1 passes. Step 2 fails.

Every field the server omits falls back to a default and **nothing is left
`undefined`** — an unsent boolean would otherwise read as "capability off" and an unsent interval as `NaN`. Screenshots, clipboard
tracking and keylogging stay off whatever the server asks: that decision
belongs on the machine, not to whoever can answer the config endpoint.

A failed refresh keeps the last good config, and `lastConfigSync` stays unset
if no refresh ever succeeded.
