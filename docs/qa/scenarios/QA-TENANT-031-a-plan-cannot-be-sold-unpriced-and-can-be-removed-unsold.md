# QA-TENANT-031 — A plan cannot be sold unpriced and can be removed unsold

## Preconditions

- Platform Admin, signed in as a `PLATFORM_OWNER`.

## Steps

1. Run `npm --workspace api run test -- plan-lifecycle one-self-service-gate`.
2. Create a plan through **Plans → New**.
3. Check the public plans endpoint and the landing pricing page.
4. Open the Plans list and read the Publication and Sales model columns.
5. `DELETE /api/super-admin/plans/:planId` for the plan just created.
6. Repeat step 5 against a plan that has prices or subscribers.

## Expected Result

- Both suites pass.
- The new plan is `DRAFT` and does not appear in the public catalogue.
- Publication and Sales model show values for every row, not em dashes.
- The unpriced, unsold plan is deleted.
- The priced or subscribed plan is refused, with a message naming the reasons
  and pointing at deactivation.

## Notes

`one-self-service-gate.spec.ts` is run alongside deliberately. Writing
`isPublic: false` at creation is the obvious way to make a plan non-public and it
is wrong: BUG-0223 retired that boolean because two gates that can disagree are
worse than one. `publicationStatus` is the authority. That invariant caught this
exact mistake while BUG-1749 was being fixed.

Two plans in production were created in the broken state. They can now be
deleted, but only while they carry no prices — check first.
