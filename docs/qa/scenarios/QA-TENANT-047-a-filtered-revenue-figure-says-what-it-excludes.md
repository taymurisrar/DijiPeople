# QA-TENANT-047 — A filtered revenue figure says what it excludes

## Preconditions

- Platform Admin, signed in as a `PLATFORM_OWNER`.
- Succeeded payments in a currency other than the platform's reporting currency
  — production has QAR payments against a PKR default.

## Steps

1. Run `npm --workspace api run test -- promotion-safety`.
2. Open the Control Hub and read the revenue figures and the header chips.
3. Hover the exclusion chip.
4. In Settings → Platform → General, note the reporting currency.

## Expected Result

- The suite passes.
- A zero revenue figure is accompanied by a chip naming the excluded
  currencies.
- The hover shows the payment count and total per excluded currency.
- With nothing excluded, no chip appears.

## Notes

This does **not** make the number right. The reporting currency is a commercial
decision the owner has to make — QA declined to make it and so did this fix.
What changed is that "PKR 0" no longer reads as "we earned nothing" when the
truth is "we earned QAR 160 and this figure does not count it".

Setting the reporting currency to QAR is one reversible edit on one screen, and
it should make both the chip disappear and the figures populate. If it does not,
the filter is wrong in a way this scenario does not cover.

The deeper options BUG-1745 lists — converting to a reporting currency, or
showing per-currency totals — are larger product work and still open.
