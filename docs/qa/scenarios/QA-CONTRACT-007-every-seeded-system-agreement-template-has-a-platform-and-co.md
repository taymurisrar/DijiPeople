# QA-CONTRACT-007 — Every seeded system agreement template has a platform and counterparty signature block

## Preconditions

A freshly seeded database (`seed-config`).

## Steps

1. For each of the nine `PLATFORM_CONTRACT_TEMPLATES`, inspect its content for
   `{{signature.platform.name}}`, `{{signature.platform.date}}`,
   `{{signature.counterparty.name}}`, `{{signature.counterparty.date}}`.
2. Run `outOfContextPlaceholders` over each template's content.
3. Generate an executed agreement from an unedited system template with no
   DijiPeople signer.
4. Repeat with a DijiPeople signer.

## Expected Result

Every template in step 1 contains all four tokens. Step 2 is empty for every
template. Step 3's platform signature line is removed entirely (ADR-0021), not
shown as "Not signed". Step 4 keeps the platform line, filled from the real
signer.
