# QA-PLATFORM-017 — Every list page either deletes or says why it will not

## Preconditions

A partner with no leads, commissions, agreements, portal users or referral
links; a partner that has at least one of those; a partner inquiry that was
never converted; and one that was.

## Steps

1. `npm --workspace api run test -- partner-deletion`
2. `npm --workspace admin run test -- platform-module-capabilities`
3. Open **Partners**, select the clean partner, and delete it from **More**.
4. Select the clean one *and* the one with commissions together, and delete.
5. Open **Partner inquiries** and delete a converted one.
6. Open **Invoices**, **Tenants** and **Contracts**. Open **More** on each.
7. Check the audit log for the deletions from steps 3 and 4.

## Expected Result

Step 3: deleted, with a confirmation naming the count.

Step 4: the clean one is deleted and the other is **kept**, named, with its
dependency counted — "Kept 1: Acme Ltd — it still has 2 commission record(s)".

Step 5: refused, because the inquiry is that partner's origin.

Step 6: Delete is **present and disabled** on all three, each carrying a
different reason and naming the non-destructive action instead — void the
invoice, erase the tenant through the governed flow, supersede the agreement.

Step 7: one audit row per successful bulk delete, listing what was requested,
what was deleted and what was refused.

## Notes

Step 4 is the contract, not a nicety. Refusing a batch of twenty because one row
has a commission makes the operator bisect the selection by hand — the same
information, and all of the work.

Considerations:

- **Step 6 is the half that answers the original report.** "There is no Delete
  button on any module" was true and the absence was mostly correct; what was
  missing was the reason. A disabled control carrying one is the fix, not a
  destructive control.
- The server is still the authority. `PlatformRuntimeService.remove` throws for
  every module outside its switch, so a UI change alone cannot make any of the
  refused modules deletable.
- Deleting real partner data is destructive and irreversible. Run steps 3–5
  against seeded demo records, never against a customer's.
