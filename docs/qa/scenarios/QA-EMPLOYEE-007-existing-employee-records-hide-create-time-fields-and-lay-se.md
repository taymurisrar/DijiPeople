# QA-EMPLOYEE-007 — Existing employee records hide create-time fields and lay sections out two across at tablet width

## Preconditions

- An existing employee record with an owner.
- A user record with roles, and permission to assign roles.

## Steps

1. Open the employee record → Record Status popover.
2. Open the More tabs menu; press Escape. Open it again; click elsewhere. Open it
   again; trigger Assign.
3. Read System Information on the existing record; then open New employee.
4. View the Summary tab at 820px and at 1440px.
5. Open the user record → Roles → Assign; tick a role; Save & Close.
6. If editing is enabled, change Employment Status from the popover in edit mode
   and save.

## Expected Result

- Step 1: Employment Status and Owner (a name only); no Sub Status; no duplicate
  Status.
- Step 2: the menu closes each time; it is closed when the Assign dialog opens,
  and focus returns to More after Escape.
- Step 3: the existing record has no Provision System Access or Send Invitation
  Now; New employee still has both.
- Step 4: two section columns at 820px, three at 1440px.
- Step 5: the panel sits above the record action bar; each checkbox is named by
  its role; an "Assigned." toast appears; Assigned On is formatted per tenant
  settings.
- Step 6: the change saves.
