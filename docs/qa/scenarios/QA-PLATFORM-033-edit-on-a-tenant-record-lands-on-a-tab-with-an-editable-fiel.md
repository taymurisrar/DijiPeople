# QA-PLATFORM-033 — Edit on a tenant record lands on a tab with an editable field

## Preconditions

A tenant record open in `apps/admin` on its default (Overview) tab, which has
no writable field; the writable fields (`name`/`displayName`/`legalName`)
live on the Configuration tab.

## Steps

1. Open a tenant record, remaining on the default Overview tab.
2. Click Edit.
3. Observe which tab is active and whether it shows an editable field.
4. Repeat on a module/tab combination where the current tab already has an
   editable field, and on one where no tab has anything editable.

## Expected Result

Clicking Edit switches to the first tab (in the record's own tab order)
containing an editable field — here, Configuration — when the current tab has
none. If the current tab already has an editable field, it stays selected. If
no tab has anything editable, no tab switch occurs. A field that would not
actually render as an input (`hidden`, failing `visibleWhen`, or a
timeline/relatedRecords/process type) is never counted as a reason to switch.
