# QA-LANDING-022 — Customer-facing catalog copy carries no raw enum value

## Preconditions

None. The catalog is a static export.

## Steps

1. Scan every `description` and `label` in `TENANT_FEATURE_DEFINITIONS`, and
   every `label` in `TENANT_SETTING_CATEGORIES`, for `SCREAMING_SNAKE` tokens.
2. Allow genuine acronyms (`HR`, `API`, `SLA`, `PDF`, `CSV`, …).
3. Check the Timesheets description specifically.
4. Open `/features` and `/plans` and read the module cards.

## Expected Result

- **Steps 1–2** — no entry contains a raw enum value. The allow-list matters:
  a rule that banned every capitalised run would fail on legitimate copy and be
  deleted, which is worse than having no rule.
- **Step 3** — reads "Monthly timesheets, submission, and approval workflows."
  Sentence case, and factually accurate: `Timesheet` is keyed
  `@@unique([tenantId, employeeId, year, month])`, so a period *is* a calendar
  month.
- **Step 4** — the same strings render as prose on both public pages.
