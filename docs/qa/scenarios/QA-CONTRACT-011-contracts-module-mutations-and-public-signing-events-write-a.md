# QA-CONTRACT-011 — Contracts module mutations and public signing events write a platform audit row

## Preconditions

A contract in draft; a signature request being completed, declined and
sent a change request against it.

## Steps

1. Create, update, void, terminate, amend, renew and send an agreement for
   signature.
2. Add/update a party, field and template on the agreement.
3. Complete a signature, decline one, and request changes on another.
4. Query `GET /platform/audit-logs` (or `PlatformAuditLog` directly) for each
   action.

## Expected Result

Every mutation in steps 1-2 writes a `PlatformAuditLog` row
(`tenantId: 'platform'`) alongside the existing `ContractTimeline` row, via
the same `timeline`/`timelineTx` helper both write through. Step 3's rows
carry `actorUserId: null` (the actor is the external signer, not a platform
user) with the signer's name/email/role in `afterSnapshot`. Step 4 finds a
matching row for every action in steps 1-3.
