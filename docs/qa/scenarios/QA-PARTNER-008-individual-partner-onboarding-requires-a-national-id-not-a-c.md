# QA-PARTNER-008 — Individual partner onboarding requires a national ID, not a company registration number

## Preconditions

A partner onboarding submission in progress for both an INDIVIDUAL and a
COMPANY applicant.

## Steps

1. Submit INDIVIDUAL onboarding data with `nationalIdNumber` but no
   `registrationNumber`.
2. Submit COMPANY onboarding data with no `registrationNumber`.
3. Submit COMPANY onboarding data with no `nationalIdNumber` (it should never
   be asked for one).
4. Create/update a COMPANY partner via admin with no `companyName`.
5. Create/update an INDIVIDUAL partner via admin with no
   `contactFirstName`/`contactLastName`.

## Expected Result

Step 1 passes validation. Step 2 is refused, naming `registrationNumber` as
missing. Step 3 is unaffected — COMPANY is never asked for a national ID.
Steps 4-5 each return `400` naming the missing type-appropriate field.
