# QA-CONTRACT-006 — A template with a dated signature line can be sent, and the signed copy shows the real signing date

## Preconditions

A partner agreement from `CUSTOMER_SERVICE_STANDARD` (or another template with
`{{signature.platform.date}}`/`{{signature.counterparty.date}}`), with a stale
manually-entered `signature.platform.date` document field.

## Steps

1. Send the agreement for signature without filling the date fields.
2. Attempt `PATCH /contracts/:id/document-fields` with
   `signature.counterparty.date`.
3. Inspect the signing version's stored snapshot.
4. Complete signing.
5. Open the executed PDF and read the printed signature date.

## Expected Result

Step 1 succeeds — the send is never blocked by an unresolved
`signature.*.date`. Step 2 returns `400
CONTRACT_SIGNATURE_FIELD_NOT_EDITABLE`. Step 3's snapshot has no `signature.*`
key. Step 5 prints the real `SignatureEvidence.signedAt` timestamp — never the
stale manually-entered date.
