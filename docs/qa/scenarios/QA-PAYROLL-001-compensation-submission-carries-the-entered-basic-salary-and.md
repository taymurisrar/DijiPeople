# QA-PAYROLL-001 — Compensation submission carries the entered basic salary and derives nothing

## Preconditions

A tenant with at least one active pay component, and a user with
`payroll.write`.

## Steps

1. `npm --workspace web run test -- compensation-runtime`.
2. Manual form: open Payroll → Employee Compensation → New, fill Basic Salary
   and one component, and save.
3. Repeat with Basic Salary left empty.

## Expected Result

Step 1 passes. In step 2 the record stores exactly the basic salary that was
typed, and the component reaches the API as `amount` or `percentage` according
to its `calculationMethod`.

In step 3 the API answers **400 naming `basicSalary`**. It must not invent a
value — neither the first component's amount nor a substituted zero. An
employee recorded as earning a number nobody entered is worse than a refused
save.
