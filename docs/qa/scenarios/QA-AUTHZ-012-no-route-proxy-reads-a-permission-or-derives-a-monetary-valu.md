## Preconditions

A checkout of the repository.

## Steps

1. `npm run check:proxies-decide-nothing`.
2. Adversarial form: add a handler under `app/api/**` that reads
   `permissionKeys`, or assigns `basicSalary`, and re-run.

## Expected Result

Step 1 passes over every handler in web, admin and landing. Step 2 fails,
naming the file and which shape it matched.

Reading the session to *forward* it is fine and is what these handlers are
for; reading it to *branch* is not. A second source of truth the authority
cannot see, correct or audit is a defect even when it is fail-closed.
