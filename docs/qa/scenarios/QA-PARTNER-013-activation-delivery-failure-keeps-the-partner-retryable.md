# QA-PARTNER-013 — Activation delivery failure keeps the partner retryable

## Preconditions

An activation-ready partner whose portal contact has not been invited, and a
communications provider that can return `FAILED` before returning `SENT`.

## Steps

1. Run Activate while the provider returns `FAILED`.
2. Inspect the partner and portal identity state.
3. Run Activate again after the provider returns `SENT`.

## Expected Result

The first request returns `PARTNER_INVITATION_DELIVERY_FAILED`, keeps the
partner and account lifecycle unchanged, and revokes only its pending
credential. The retry succeeds and records the activation once.
