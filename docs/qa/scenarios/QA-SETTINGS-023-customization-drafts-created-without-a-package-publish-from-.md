# QA-SETTINGS-023 — Customization drafts created without a package publish from Publish Center

## Preconditions

- Tenant 1: a fresh tenant with no Custom Package.
- Tenant 2: the demo tenant, which holds legacy drafts in "Unassigned Draft
  Customizations" and the "QA Walkthrough Package".
- An administrator holding `customization.publish`.

## Steps

1. Tenant 1: create a module, a field, a view and a choice list, leaving every
   package choice blank.
2. Open Publish Center, select all, Validate, then Publish.
3. Tenant 2: open Publish Center and Validate the legacy drafts.
4. Open Move to package, move the legacy drafts to "<Tenant> Customizations",
   Validate, then Publish.
5. Validate a set containing a view the administrator created.

## Expected Result

- Step 1-2: the drafts are listed under "<Tenant> Customizations"; validation
  reports ready; publish succeeds and the runtime metadata snapshot version
  increments.
- Step 3: one blocking issue per legacy draft, naming the legacy package.
- Step 4: move targets include "<Tenant> Customizations" and "QA Walkthrough
  Package"; after the move, validation and publish both succeed.
- Step 5: no "is a default component" warning for the administrator's view.
- For any selection, validate reports invalid exactly when publish refuses.
