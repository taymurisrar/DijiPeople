# QA-TENANT-022 — An agreement template refuses a source that cannot fill it

## Preconditions

- A published contract template requiring `tenant.*` fields.
- A customer with no tenant, and a provisioned tenant.

## Steps

1. Run the contracts spec: `npm --workspace api run test -- source-fills-template`.
2. In admin, create an agreement from a **customer** using a tenant-provisioning template.
3. Repeat from a **tenant**.

## Expected Result

- Step 2 is refused with `CONTRACT_SOURCE_CANNOT_FILL_TEMPLATE`, naming the
  namespaces that cannot be filled.
- Step 3 succeeds.
- No document is generated containing raw handlebars tokens.

## Notes

Read the generated body **and** `GET /api/contracts/{id}/document-fields`. The
original report was made from the rendered document alone and got two details
wrong: customer fields had in fact resolved, and the template used no
unregistered keys.

Only required placeholders are checked. Optional terms are meant to be filled
later, and the contract, platform, counterparty, sla and signature namespaces
are filled after the source rather than by it.
