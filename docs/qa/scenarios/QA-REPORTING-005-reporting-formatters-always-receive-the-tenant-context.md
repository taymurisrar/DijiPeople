# QA-REPORTING-005 — Reporting formatters always receive the tenant context

## Preconditions

A tenant whose date, number or currency format differs from the built-in fallback.

## Steps

1. Open a report runner page and read the browser console.
2. Fetch the same URL's server-rendered HTML and compare its date cells with the hydrated DOM.
3. Open an analytics surface carrying currency or percentage tiles and a chart.

## Expected Result

No React #418 in the console. Server HTML and hydrated DOM render every date, number and currency identically, in the tenant's format. Every context-taking formatter call passes a context.

## Notes

Do not fix this by making the module-level default work on the server: it is shared between concurrent requests in one Node process and could render one tenant's response with another tenant's formatting. Explicit threading is the architecture.
