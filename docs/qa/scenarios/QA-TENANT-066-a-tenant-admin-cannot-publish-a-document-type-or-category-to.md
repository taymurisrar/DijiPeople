# QA-TENANT-066 — A tenant admin cannot publish a document type or category to every tenant

## Preconditions

Two tenants, A and B, each with a tenant admin holding
`documents.types.manage`. One global (tenant-less) document type exists.

## Steps

1. As A: `POST /documents/types` with `isGlobal: true`.
2. As A: `POST /documents/categories` with `isGlobal: true`.
3. As A: `PATCH /documents/types/<the global type's id>`.
4. As A: create an ordinary type; as B, `GET /documents/types` and
   `GET /documents/types/<A's type id>`.

## Expected Result

- Steps 1 and 2 answer 403 `DOCUMENT_GLOBAL_FORBIDDEN`, and no row is written.
- Step 3 answers 400; the global type is unchanged.
- In step 4, B's list does not contain A's type and the read answers 404.
