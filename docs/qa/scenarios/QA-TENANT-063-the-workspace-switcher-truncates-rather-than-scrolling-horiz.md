# QA-TENANT-063 — The workspace switcher truncates rather than scrolling horizontally

## Preconditions

A user who is a member of several workspaces, at least one with a long name, so
the switcher has something to overflow with.

A viewport narrow enough that the longest name cannot fit — the defect was
invisible at desktop width.

## Steps

1. Sign in and open the avatar menu.
2. Read the workspace switcher at desktop width.
3. Narrow the viewport to tablet and then mobile width and read it again.
4. Attempt to scroll the menu sideways.

## Expected Result

- A name too long for the menu is **truncated**, and the full value stays
  available to assistive technology rather than being lost.
- The menu never scrolls horizontally at any width. Two mechanisms caused this
  and both must stay fixed: a grid item's default minimum width defeating a
  truncate rule, and `overflow-y-auto` quietly enabling overflow on the other
  axis too.
- The switcher shows the workspaces the user is actually a member of.
