# QA-PLATFORM-065 — A published plan can be unpublished, archived and then deleted

## Preconditions

A non-production database with seed:config, seed:admin and seed:commercial.
A plan that is PUBLISHED, inactive, custom-only and has no prices,
subscriptions or references (the production Enterprise+ shape). Signed in as
the platform super admin.

## Steps

1. Open the plan record.
2. Unpublish it and confirm.
3. Open More.
4. Delete it and confirm.

## Expected Result

1. Unpublish is offered; Publish is not.
2. The confirmation says it leaves the pricing page and that existing
   subscriptions are unaffected — not "permanently deletes". The header shows
   Draft and PLAN_UNPUBLISHED is audited.
3. More offers Publish and Archive.
4. The delete dialog allows it; the plan is removed and platform.plan_deleted
   is audited.
