# QA-SETTINGS-022 — Every custom field type saves from the Add field dialog

## Preconditions

- A tenant administrator holding the customization permissions.
- A custom module exists (for example `qaAsset`).
- Browser devtools network tab open.

## Steps

1. Module → Fields → Add field. Create a Choice field with two options.
2. Create a Reference field targeting Employees.
3. Create a Number field, a Date and time field and a Yes/No field.
4. Create a Text field with Maximum length left blank.
5. Create a Text field with Maximum length `0`.
6. Directly `POST` a column-create body carrying `maxLength: null` for a Choice
   field (a stale client).

## Expected Result

- Steps 1-4: each request returns 201; the request body carries no `maxLength`
  for types without a length; each field appears in the list with a
  human-readable type label.
- Step 5: refused, with the error shown on the Maximum length field.
- Step 6: 201; `null` means "no length".
