# QA-SETTINGS-038 — Customization tiles follow page permissions, not roles

## Preconditions

A tenant user whose role is System Admin (not Global Administrator, not System Customizer) and who holds the customization keys. The demo tenant owner qualifies.

## Steps

1. Automated: run `npx jest --config jest.config.js customization-navigation-access` in apps/web.
2. Browser: sign in as that user and open Settings → Customization.
3. Open the Packages tile, then Import.

## Expected Result

- The spec passes all 10 cases.
- The landing shows Modules and Sidebar Designer under Runtime Metadata, a Packages group with Packages, and a Publishing group with Publish Center, beside Fields, Forms, Views, Action Bars and Widgets.
- Packages lists the workspace packages with Export and Import actions, and Import opens the import wizard.
