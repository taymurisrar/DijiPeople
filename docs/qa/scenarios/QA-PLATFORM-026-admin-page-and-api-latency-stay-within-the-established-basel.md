# QA-PLATFORM-026 — Admin page and API latency stay within the established baseline

## Preconditions

A signed-in platform user against a deployed environment. Against **production**,
keep it read-only and bounded: GET only, no more than 8 concurrent, short
bursts. The tenant app and the landing site share the service.

## Steps

1. For each of `/`, `/tenants`, `/customers`, `/leads`, `/plans`, `/invoices`,
   `/settings/monitoring`, `/settings/monitoring/error-logs` and `/security`:
   navigate three times from `about:blank` and take the median of DOM
   content-loaded, time to settle, and TTFB.
2. Call the runtime list APIs five times each and take the median.
3. Issue 8 concurrent GETs to one endpoint, **each with a distinct URL**, and
   compare the slowest against the single-request time.

## Expected Result

Against the 2026-08-26 production baseline:

| Measure | Baseline |
|---|---|
| TTFB, every route | ~202ms, flat |
| Page settle, median | ~4s |
| Runtime list API, median | 465–835ms |
| Degradation at 8 concurrent | ~1.4× |

No route should be an order of magnitude off its siblings. `/settings/monitoring`
was, at 25–31s against a ~4s median — that is BUG-1419, a prefetch storm against
a route that does not exist. It must be re-baselined after that fix rather than
accepted as this screen's cost.

## Notes

**Step 3 says "each with a distinct URL" for a reason.** Measured with identical
URLs, this produces a clean linear ladder — 1.0×, 2.0×, 4.3×, 6.1×, 9.4× at
n=1…8 over HTTP/2 — which reads exactly like server-side serialization and is
not. It is the browser coalescing identical in-flight requests. At n=8 against
the same endpoint: identical URL 4216ms, distinct URL 667ms.

That produced a convincing false finding during the run that established this
baseline. It was retracted only because the two variants were compared directly,
which is why the comparison is written into the steps rather than left to
judgement.

The baseline is single-user. It says nothing about sustained or write load, or
about concurrency above 8 — those were excluded from the production run by owner
decision and remain untested.
