# QA-SETTINGS-037 — Claims is reachable from the sidebar for each kind of user

## Preconditions

Tenant users with, respectively, `claims.read-all`; only `claims.read-own`;
self-service with both; a tenant administrator role; neither permission.

## Steps

1. Resolve the sidebar for each user.
2. In production, sign in as the tenant owner and open the sidebar.

## Expected Result

- `claims.read-all` (not self-service) and tenant administrators see **Claims**
  linking to `/claims`, which has the New claim button.
- `claims.read-own` holders and self-service users see **My Claims** linking to
  `/me/claims`.
- A user with neither permission sees no claims entry.
