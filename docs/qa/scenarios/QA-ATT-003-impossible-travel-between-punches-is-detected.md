# QA-ATT-003 — Impossible travel between punches is detected

## Preconditions

Two punches with locations and timestamps.

## Steps

1. Two punches at plausible distance and interval.
2. Two punches requiring implausible speed.
3. Two punches at the same location moments apart.

## Expected Result

Only the implausible pair is flagged. Flagging is a signal for review, never an automatic rejection of somebody's attendance.

## Notes

A false positive here is an accusation, so the threshold matters as much as the detection.
