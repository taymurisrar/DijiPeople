# QA-EMPLOYEE-003 — The employee record export writes lookup display names, never ids

## Preconditions

An employee record with Owner, Reporting Manager, Emergency Contact Relation
Type, Employment Status, a date and a Yes/No field set.

## Steps

1. Open the record and choose Export in the command bar.
2. Open the downloaded CSV.

## Expected Result

- Owner, Reporting Manager and Emergency Contact Relation Type hold names.
- No cell anywhere in the file is a UUID.
- Employment Status reads its label (for example "Active"); dates and Yes/No
  values read as before.
- A lookup whose name the page does not know exports as an empty cell, not an id.

## Notes

Created 2026-09-13 at `4d249b40` for REG-497. The export is shared by every
module using the client-side record export; spot-check one other module.
