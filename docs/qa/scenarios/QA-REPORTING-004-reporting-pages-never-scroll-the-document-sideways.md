# QA-REPORTING-004 — Reporting pages never scroll the document sideways

## Preconditions

A signed-in tenant user with access to the reporting workspace.

## Steps

1. Open each reporting page at viewport widths 1024, 1280, 1440 and 1920.
2. At each width read `document.documentElement.scrollWidth` and `clientWidth`.
3. Open a report whose table is wider than the viewport.

## Expected Result

`scrollWidth <= clientWidth` at every width on every page: the document never scrolls sideways. A table wider than the viewport scrolls inside its own `overflow-x: auto` container instead of widening the page.

## Notes

1440 is the width that exposed this; 1920 has room and below `xl` the header stacks, so testing only the extremes misses it. Tailwind v4 emits `min-width:calc(var(--spacing) * 0)`, not `min-width:0` - grep the built CSS for the utility class, not the literal value.
