# QA-AGENT-007 — A capability that is off captures nothing from the employee's machine

## Preconditions

A checkout of the repository.

## Steps

1. `npm --workspace agent-desktop run test -- activity-tracker`.
2. Adversarial form: read the active window before checking the capability
   flags, and re-run.

## Expected Result

Step 1 passes. Step 2 fails.

A capability that is off does not read and discard: `active-win` is **never
called**, so the title never exists in the process. Either the platform feature
flag or the tenant tracking flag being off is enough. Titles are trimmed and
bounded at 300 characters, because any application can set a window title.

The ACTIVE/IDLE/AWAY boundaries are exact, tracking-off reports AWAY rather
than a false ACTIVE, and an inverted threshold pair is refused rather than
guessed at.
