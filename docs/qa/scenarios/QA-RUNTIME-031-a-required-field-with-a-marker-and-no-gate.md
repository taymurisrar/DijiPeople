## Preconditions

A tenant on which the affected surface is reachable, and a signed-in user with
the permissions the surface requires. REG-333 in the regression register carries
the full root cause; this scenario is the reusable check, not the diagnosis.

## Steps

An empty "Assigned On" is blocked with that error on `effectiveFrom` and nothing shown anywhere contains `effectiveFrom` or `ISO 8601`; supplying it validates; every other registry-declared required quick-create field is gated the same way; absent metadata does not block.
