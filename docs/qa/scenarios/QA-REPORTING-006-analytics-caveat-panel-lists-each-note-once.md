# QA-REPORTING-006 — Analytics caveat panel lists each note once

## Preconditions

The reporting semantic registry, with at least one surface whose metrics and data source both carry caveats.

## Steps

1. Collect every caveat declared on every data source and every metric.
2. Compare each pair that differs as a string, by word-set overlap.
3. Open an analytics surface and read the "How to read these numbers" panel.

## Expected Result

No two caveats that differ as strings share 60% or more of their vocabulary, and the rendered panel lists each note once. Identical strings on a source and its metric are correct and expected — that is the intended arrangement, and the union deduplicates them.

## Notes

Do not test this with a prefix comparison. The pair that shipped diverges at the fourth word, so a prefix long enough to avoid false positives sits past the divergence and the test passes on a broken tree — which is exactly what happened on the first attempt.
