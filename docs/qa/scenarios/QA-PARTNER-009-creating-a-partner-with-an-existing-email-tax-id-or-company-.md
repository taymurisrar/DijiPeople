# QA-PARTNER-009 — Creating a partner with an existing email, tax id or company name is refused

## Preconditions

An existing `Partner` with a known `email`, `taxId` and `companyName`; an
existing `PartnerInquiry` in a non-`INQUIRY` status; a lead with no
`partnerId` whose email matches an existing partner.

## Steps

1. `POST /partners` with the existing partner's `email` (different casing).
2. `POST /partners` with the existing partner's `taxId` (different
   punctuation).
3. `POST /partners` with the existing partner's `companyName` (COMPANY type).
4. Submit a public inquiry with the same `taxId`/`registrationNumber` as an
   existing partner's onboarding submission, under a different email/company
   name.
5. Call `qualifyInquiry` on the lead with no `partnerId` whose email matches
   an existing partner.
6. Repeat step 1 with a genuinely new, non-matching email.

## Expected Result

Steps 1-4 each return `409 Conflict` naming the existing partner's display
name, code and status. Step 5 returns `409` before the transaction opens — no
second `Partner` row is created. Step 6 succeeds normally.
