# QA-PLATFORM-064 — Owner names are stored as entered, placeholders are repaired, and every lookup links

## Preconditions

A non-production database with seed:config, seed:admin, seed:commercial and
seed:demo applied. One tenant owner stored as "<first> Owner" whose customer
contact and onboarding have no surname, and one non-owner user surnamed Owner.
Signed in as the platform super admin.

## Steps

1. Run repair:owner-names (dry run), then with --apply, then again.
2. Open the customer → Summary → Tenant primary owner.
3. Follow the link.
4. On the outlined owner row, Actions → Edit details → set a last name → Save.
5. Open the tenant record and read the header.

## Expected Result

1. The dry run lists the owner only; --apply repairs it to "<first>" and
   writes USER_PLACEHOLDER_NAME_REPAIRED; the second run finds nothing; the
   non-owner keeps "Owner".
2. The owner shows the repaired name and is a link.
3. It opens the tenant on Access & Security with the owner row outlined.
4. "Owner details updated." and the row shows the new full name.
5. The header's Primary Tenant Owner names the owner, not "Unassigned".
