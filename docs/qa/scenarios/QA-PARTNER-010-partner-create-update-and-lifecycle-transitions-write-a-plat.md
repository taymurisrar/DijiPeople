# QA-PARTNER-010 — Partner create, update and lifecycle transitions write a platform audit row

## Preconditions

A platform operator session with `platform-users.manage`/partner permissions;
an existing partner and an existing onboarding application.

## Steps

1. Create a partner.
2. Update the partner's commission rate.
3. Transition the partner's lifecycle (e.g. start-review, approve).
4. Qualify and reject a partner inquiry.
5. Decide an onboarding review, and activate a partner.
6. Query `GET /platform/audit-logs` (or `PlatformAuditLog` directly) for each
   action above.

## Expected Result

Every action in steps 1-5 writes an `AuditService.log()` entry
(`tenantId: 'platform'`) with the acting platform user id and, where
applicable, before/after snapshots, alongside the existing `PartnerTimeline`
row. Step 6 finds a matching row for each action.
