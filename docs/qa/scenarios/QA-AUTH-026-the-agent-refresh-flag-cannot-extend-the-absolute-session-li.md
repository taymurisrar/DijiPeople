# QA-AUTH-026 — The agent refresh flag cannot extend the absolute session lifetime

## Preconditions

An isolated database with the fixtures named in the test.

## Steps

1. Sign an agent in, then set the stored absolute expiry in the past.
2. POST /agent/auth/refresh with startNewSession true.
3. Repeat with only the idle limit exceeded (control).

## Expected Result

Step 2 is 401 "Agent session has expired." and mints nothing. Step 3 resumes the session on the same absolute expiry.
