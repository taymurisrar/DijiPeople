# QA-PLATFORM-036 — Opening a contract template or signature request from its admin list shows the record

## Preconditions

A SUPER_ADMIN session; at least one contract template and one signature
request.

## Steps

1. `GET /api/platform-runtime/contract-templates` and take an id.
2. `GET /api/platform-runtime/contract-templates/<id>`.
3. Repeat steps 1-2 for `signature-requests`.
4. Open each record from its list in the admin UI.

## Expected Result

Step 2 returns the record (via `ContractsService.getTemplate`), not `404`.
Step 3 returns the signature request (via `getSignatureRequest`), not `404`.
Step 4 shows the record in the admin UI for both module types.
