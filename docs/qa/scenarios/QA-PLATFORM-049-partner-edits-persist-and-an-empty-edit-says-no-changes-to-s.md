# QA-PLATFORM-049 — Partner edits persist and an empty edit says No changes to save

## Preconditions

A platform admin and an existing partner.

## Steps

1. Run `node --test scripts/runtime-write-contract.test.mjs` and `npm run check:runtime-schema` from the repository root.
2. Browser: edit the partner's Phone and Default commission, save, then reload.
3. Browser: click Edit, then Save without changing anything.

## Expected Result

- The parser tests pass and the schema matches.
- After reload, both values have persisted.
- Saving without changes shows "No changes to save" and sends no request.
