# QA-AUTH-018 — Every platform sign-in outcome writes a platform audit row, never the attempted password

## Preconditions

A platform admin account; the admin sign-in page.

## Steps

1. Sign in with a wrong password.
2. Sign in with an unknown address.
3. Lock the account (five wrong passwords), then attempt the correct
   password.
4. Enter a wrong MFA code on an MFA-enrolled account.
5. Sign in successfully with MFA.
6. Inspect each resulting `PlatformAuditLog` row.

## Expected Result

Steps 1-4 each write an `AUTH_LOGIN_FAILED` row with the specific
`failureReason`, and steps 1-3 return the identical 401 body regardless of
cause. Step 5 writes `AUTH_LOGIN_SUCCEEDED` with the actor, `mfaResult`,
session id, and forwarded IP/user agent. No row in step 6 contains the
attempted password.
