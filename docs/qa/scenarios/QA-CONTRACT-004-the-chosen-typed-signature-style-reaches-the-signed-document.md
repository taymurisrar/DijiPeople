# QA-CONTRACT-004 — The chosen typed-signature style reaches the signed document

## Preconditions

An open signature request link on the public signing page.

## Steps

1. Choose "Typed" signature, enter a name, select "Script".
2. Complete signing.
3. Inspect the network request to `/public/signatures/:token/sign`.
4. Open the generated PDF and DOCX for the signed agreement.
5. Repeat with "Classic" selected.

## Expected Result

Step 3's request body includes `typedStyle: 'SCRIPT'`. The PDF renders the
typed name in `Times-Italic` (distinct from Classic's `Helvetica`), and the
DOCX's `word/document.xml` contains an actual `Times New Roman` run. The style
persists and survives document regeneration since it is stored on
`SignatureEvidence`, not recomputed.
