# QA-TENANT-036 — A destructive dialog names what it will destroy

## Preconditions

- Platform Admin, signed in as a `PLATFORM_OWNER`.
- A module with several deletable records.

## Steps

1. Run `npm --workspace admin run test -- destructive-confirm`.
2. Open a record and choose Delete. Read the dialog.
3. Return to the list and select three rows. Read the toolbar.
4. Choose Delete. Read the dialog.
5. Select more than five rows and repeat.

## Expected Result

- The suite passes.
- Step 2 names the record in the title.
- Step 3 shows "3 selected of n" **before** any dialog opens.
- Step 4 states the count and lists the three names.
- Step 5 names five and says how many more.

## Notes

Step 3 is the one worth insisting on. A dialog is a last chance; the operator
should know what they have selected before they reach it, and previously the list
showed nothing at all.

Watch the number agreement: "Delete 1 partner?" and "Delete 5 partners?". The
old copy said "selected records" for every case, which is how a count of one and
a count of forty looked identical.
