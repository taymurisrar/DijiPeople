# QA-SETTINGS-026 — Removed explanatory helper text stays removed from tenant screens

## Preconditions

- A tenant administrator with customization, employee and notification settings
  access.
- An employee record with a reporting chain; a user record with roles.

## Steps

1. Open the login page at 1440px and at 400px.
2. Open an employee record: the Organization section, View hierarchy, and Assign.
3. Open a user record → Roles → Assign.
4. In Customization open Create module, Add field, Add choice list, Add
   relationship, Add action bar, Create view and the Sidebar Designer.
5. Open Settings → Notifications: Notification Rules, Email Templates (list,
   system template, new template) and Email Providers.
6. Use a screen reader or the accessibility tree on the Add field dialog.

## Expected Result

- Step 1: "Remember me" and "Activate account" each sit on one line; no
  "Keeps you signed in…" sentence.
- Steps 2-5: none of the twelve texts listed in ITEM-0183 appears; no hint is
  rendered twice; no page or panel description explains a control; the Assign
  Roles panel does not mention allocation, billing or approval; no
  "Configuration JSON is sent to the backend as-is" note.
- Step 6: the Field type and Reference target comboboxes are announced by name.
- Nothing new was added in place of a removed sentence.
