# QA-BILLING-040 — A forged, tampered or replayed Safepay webhook changes nothing

## Preconditions

The API with `SAFEPAY_WEBHOOK_SECRET` set and the raw-body parser on `/api/billing/safepay/webhook`.

## Steps

1. POST an event signed with another secret.
2. POST a correctly signed event.
3. POST the same event again.
4. POST the signed body with one field altered.
5. Make processing fail, then redeliver.

## Expected Result

- Forged and tampered bodies are refused with 400 and nothing is recorded.
- The signed event is processed and recorded once; its redelivery answers `duplicate: true` without reprocessing.
- A processing failure answers non-2xx and records `FAILED`, and the provider's redelivery is processed rather than short-circuited.
