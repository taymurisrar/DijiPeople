# QA-PLATFORM-043 — The dashboard's errors-needing-attention tile opens a list matching its count

## Preconditions

Incidents in each support status: NEW, INVESTIGATING, WAITING_ON_CUSTOMER,
FIX_IN_PROGRESS, RESOLVED and NOT_AN_INCIDENT. A platform user holding
`dashboard.read` and `monitoring.read`.

## Steps

1. Open the admin dashboard's Operations view and note "Errors needing
   attention".
2. Click the tile.
3. From the monitoring overview, open "Under investigation".

## Expected Result

Step 2 lands on the Open incidents view listing exactly the NEW,
INVESTIGATING, WAITING_ON_CUSTOMER and FIX_IN_PROGRESS incidents — as many as
the tile counted. Step 3 lists INVESTIGATING and FIX_IN_PROGRESS. "Active
users" and "Failed sign-ins" are not links.
