# QA-PAYROLL-002 — Reversing a posted payroll journal creates a second journal for the same run

## Preconditions

A database built only from the migration history, a tenant admin, and a payroll run with a POSTED, balanced journal.

## Steps

1. POST `/api/payroll/runs/<run>/journal/reverse` with a reason.
2. POST it again.
3. As another tenant's admin, POST it for the first tenant's run.

## Expected Result

Step 1 returns 2xx; the run now has an ORIGINAL and one REVERSAL journal linked both ways, the reversal's debits equal the original's credits and it balances, the original's lines are unchanged. Step 2 is 409 and creates nothing. Step 3 is 404 and changes nothing.
