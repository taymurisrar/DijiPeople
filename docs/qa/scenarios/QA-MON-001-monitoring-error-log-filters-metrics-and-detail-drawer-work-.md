# QA-MON-001 — Monitoring error-log filters, metrics and detail drawer work against real captured data

## Preconditions

Platform Admin signed in; captured error incidents across several sources, tenants and the platform sentinel.

## Steps

1. Open Monitoring → Error logs.
2. Change period, severity, status, application, environment, module and tenant.
3. Search by reference.
4. Open an incident.

## Expected Result

Filter options list only stored values (no duplicate Platform option); metrics follow the scope; the drawer shows reference, timing, request, affected context and a collapsible stack trace with no credentials or tokens.
