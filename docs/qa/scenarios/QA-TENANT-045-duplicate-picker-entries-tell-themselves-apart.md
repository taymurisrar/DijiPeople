# QA-TENANT-045 — Duplicate picker entries tell themselves apart

## Preconditions

- Platform Admin, signed in as a `PLATFORM_OWNER`.
- Two active platform users sharing a display name — "Taimur Israr" was the pair
  this was found on.

## Steps

1. Run `npm --workspace admin run test -- lookup-disambiguation`.
2. Open any record with an owner picker and read the options.
3. Open the contract template picker.
4. Look at a picker whose entries are all distinct.

## Expected Result

- The suite passes.
- The two same-named users are distinguishable — each carries its email.
- Duplicate template names are distinguishable.
- Step 4's picker is unchanged: no emails, no parentheses, no clutter.

## Notes

Step 4 is half the point. The disambiguator appears only where a label actually
repeats — showing everyone's email would clutter every picker in the console to
solve a problem that exists in two of them.

The template half of BUG-1553 asked whether the duplication is display-level or
two real records. This makes them distinguishable either way; which of the two
*should* be selectable is still a product decision and still open.
