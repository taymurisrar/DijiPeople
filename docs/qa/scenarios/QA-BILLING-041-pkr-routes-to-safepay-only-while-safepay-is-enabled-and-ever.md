# QA-BILLING-041 — PKR routes to Safepay only while Safepay is enabled and every other currency stays on Stripe

## Preconditions

`resolvePaymentProvider` with Safepay enabled and disabled.

## Steps

1. Resolve PKR, lower-case and padded PKR, USD, QAR and AED with Safepay enabled.
2. Resolve PKR with Safepay disabled.
3. Resolve USD with an explicit SAFEPAY override.

## Expected Result

- PKR routes to Safepay only while enabled; with it disabled PKR stays on Stripe, so deploying changes nothing for a live PKR buyer.
- Every other currency routes to Stripe.
- An internal override wins; it is never populated from a customer request.
