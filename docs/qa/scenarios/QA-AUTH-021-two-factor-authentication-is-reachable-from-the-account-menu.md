# QA-AUTH-021 — Two-factor authentication is reachable from the account menu and admin Settings

## Preconditions

A tenant user, with and without a linked employee record; a platform operator in admin.

## Steps

1. Automated: run `npx jest --config jest.config.js account-security-discoverability` in apps/web.
2. Web: open the avatar menu and choose Security.
3. Web: open Settings and search for two-factor.
4. Admin: open Settings → Security → Two-factor authentication.

## Expected Result

- The spec passes all 3 cases.
- Web: Security lands on My Profile scrolled to the Two-factor authentication card, for both kinds of user.
- Web: the search lists Password & Login Policies.
- Admin: the tile opens /security, showing the Two-factor authentication card.
