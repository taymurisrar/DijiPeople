# QA-AUTHZ-019 — Platform administrator tiers are held by exactly the intended roles

## Preconditions

Platform users in every platform role, and a tenant user whose token carries
`platform.administer` or `platform.*` as tenant keys.

## Steps

1. As each role: correct a lead's attribution; bulk-delete customers; act on
   another approver's contract approval step; change platform settings; open
   a tenant control-plane action.
2. As each role: bulk-modify a lead the user does not own.
3. As each role: download a platform log file.
4. Repeat step 1 as the tenant user.

## Expected Result

Step 1 succeeds only for SUPER_ADMIN, PLATFORM_OWNER and PLATFORM_ADMIN; step 2
additionally for PRESALES_MANAGER; step 3 only for SUPER_ADMIN and
PLATFORM_OWNER. The tenant user is refused everywhere in step 4.
