# QA-TENANT-037 — Dropdown labels keep their acronyms and ranges

## Preconditions

- Platform Admin, signed in as a `PLATFORM_OWNER`.

## Steps

1. Run `npm --workspace admin run test -- humanize-label`.
2. Open **Leads → New Lead** and read the Company size, Industry and Source
   dropdowns.
3. Open a contract and read its Contract type.

## Expected Result

- The suite passes.
- Company sizes read `11-50`, not `11 50`.
- Industries read `IT / Software`, not `It / Software`.
- Sources read `LinkedIn` and `WhatsApp Inquiry`.
- Contract types read `NDA`, not `Nda`.

## Notes

Display only — the values submitted and stored were always correct, so nothing
here is a data question.

Six other copies of the old humaniser remain elsewhere in the admin app
(dashboard, monitoring, signature detail, payment recheck, events page, record
status group). They render things other than lookup values and were deliberately
left alone, which makes them the likeliest place for this to reappear. If a
mangled label turns up on one of those screens, that is where to look.
