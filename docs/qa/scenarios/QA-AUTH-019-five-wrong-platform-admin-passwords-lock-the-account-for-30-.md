# QA-AUTH-019 — Five wrong platform-admin passwords lock the account for 30 minutes

## Preconditions

A platform admin account with a known correct password.

## Steps

1. Submit five wrong passwords for the account.
2. Submit the correct password immediately after.
3. Wait for the lock to expire (or advance the clock in the test), then submit
   the correct password.
4. Attempt sign-in with an entirely unknown address, and with a wrong
   password against a known address, and against the now-locked account —
   compare all three response bodies.
5. Enter a wrong MFA code repeatedly against an MFA-enrolled account.

## Expected Result

Step 1 sets `lockedUntil` 30 minutes ahead and resets the failure counter.
Step 2 is refused with the identical `"Invalid admin credentials."` body used
for a wrong password or an unknown address — never a distinct "locked"
message. Step 3 succeeds after expiry and clears the counter. Step 4's three
bodies are byte-identical (no account enumeration). Step 5's wrong MFA codes
count toward the same lock.
