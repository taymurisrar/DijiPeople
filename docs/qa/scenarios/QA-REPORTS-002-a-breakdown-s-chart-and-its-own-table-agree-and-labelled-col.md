# QA-REPORTS-002 — A breakdown's chart and its own table agree, and labelled columns show names not GUIDs

## Preconditions

A report with a breakdown dimension whose values are entity ids — the case that
produced raw GUIDs on screen — and at least one metric whose breakdown shares
are rounded for display.

Enough rows that the shares do not sum trivially to 100.

## Steps

1. Open the analytics surface and read the breakdown table.
2. Read the chart rendered from the same query beside it.
3. Compare every labelled cell against the entity it refers to.
4. Compare each share in the chart against the same share in the table.
5. Read the record-count caption under both.

## Expected Result

- Labelled columns show entity **names**, not ids. A GUID on screen means the
  label lookup did not resolve and the value was passed through.
- The chart and the table state the same numbers for the same query. They are
  formatted by shared code, so a disagreement means two rounding paths exist
  again.
- The record count matches the metric it captions, rather than counting the rows
  that happened to be loaded.
