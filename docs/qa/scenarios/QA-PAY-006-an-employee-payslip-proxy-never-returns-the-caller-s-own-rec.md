# QA-PAY-006 — An employee payslip proxy never returns the caller's own record for another id

## Preconditions

Two employees in one tenant, each with a payslip and a bank account.

## Steps

1. As employee A, request A's payslip through the web proxy.
2. As employee A, request B's payslip by id.
3. Repeat both for the bank-account proxy.

## Expected Result

Step 2 is refused. It must **not** silently return A's own record — that reads
as success to the caller and hides the authorization failure completely.

## Notes

`BUG-0039` is open. The route proxies under `apps/web/app/api/` ignored the id
and served the session's own employee, which is why this is an API scenario
against the proxy rather than against the API. No automated coverage exists for
the web proxies — that is the area's `API: GAP`.
