# QA-TENANT-014 — Every tenant control-plane method authorizes before it queries

## Preconditions

A checkout of the repository.

## Steps

1. `npx jest every-method-asserts` from `services/api`.
2. Adversarial form: delete the `assertTenantPlatformAccess` line from any
   public control-plane method and re-run.

## Expected Result

Step 1 passes. Step 2 fails, naming the method.

The check also fails a method that asserts *after* its first Prisma call: the
refusal would be correct but the row was already read.

This reads source text, so it proves a method **names** an authorization
helper, not that the helper is reached on every path. That limit is real and
stated; the property being defended is that a reader can see the authorization
without tracing a call chain.
