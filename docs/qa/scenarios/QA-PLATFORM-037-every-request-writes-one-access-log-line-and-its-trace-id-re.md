# QA-PLATFORM-037 — Every request writes one access-log line and its trace id reaches the audit trail

## Preconditions

`REQUEST_LOGGING_ENABLED=true`; an authenticated request and an
unauthenticated one; a call to `AuditService.log()` inside an active request
with no explicit `traceId` passed.

## Steps

1. Make any request and inspect the resulting access-log line.
2. Repeat unauthenticated.
3. Make a request whose handler calls `AuditService.log()` without an
   explicit `requestId`/`traceId`.
4. Inspect the resulting `AuditLog`/`PlatformAuditLog` row.
5. Call `AuditService.log()` outside any request context (e.g. a background
   job) with no explicit trace id.
6. Set `REQUEST_LOGGING_ENABLED` unset/false and repeat step 1.

## Expected Result

Step 1's line carries `method, route, statusCode, durationMs, traceId,
tenantId, userId` and never the request body, headers, query string or a
token. Step 2's line has a null identity, not a fabricated one. Step 4's row
carries the ambient trace id from step 3's request, for both tenant and
platform tables. Step 5's row has a null trace id rather than throwing. Step
6 logs nothing and attaches no `finish` listener.
