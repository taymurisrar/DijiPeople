## What "tested" means here

A documentation audit. Every claim is **verified against source at `1af3690`**;
nothing was executed against a running server, and no build or test suite was
run. Where a finding is reasoned rather than observed, the bug record's *QA
Retest* section says so explicitly.

Four parallel read-only audits ran, split by concern (structure/runtime,
auth/security, settings/UI, testing/deployment). Their headline claims were
**re-verified independently** before becoming records — three did not survive
that check unchanged, recorded under Corrections below.

## Corrections made during the run

Three subagent claims did not survive independent verification, and are recorded
because taking them at face value would have put wrong facts into durable notes:

- **"`proxy.ts` is 611 lines"** — I initially measured 532 with
  `Measure-Object -Line` and published that. `(Get-Content).Count` and a raw
  split both give **611**; the agent was right and my quick measure was wrong.
- **"Zero `Tab` key handlers"** — there are **nine**, in the form designer,
  `table-detail-shell`, `role-designer` and `form-layout-grid`. None is a modal,
  so the *conclusion* (no focus trap) holds, but the stated evidence did not.
  BUG-0043 states the corrected form.
- **"14 catch-all proxies apply no encoding"** — measured **17** of 27.

## Limitations — what this run did not do

- **No request was executed against a running API or browser.** BUG-0039,
  BUG-0041, BUG-0043 and BUG-0046 are established by reading source.
- **BUG-0046(a) is reasoned, not observed** — React effect ordering was not
  tested, which is why it is MEDIUM rather than HIGH.
- **Accessibility is a stated 13-surface sample**, not a WCAG audit. No axe or
  Lighthouse run.
- **BUG-0045's route 404s** are derived from the App Router tree plus
  `[category]/page.tsx:11-12`; no URL was requested.
- **`x-forwarded-host`** exploitability depends on hosting configuration that is
  not in this repository, so it is reported without a severity.
- `BROWSER_E2E = NOT_ATTEMPTED` — and for `apps/web` it is not attemptable.
