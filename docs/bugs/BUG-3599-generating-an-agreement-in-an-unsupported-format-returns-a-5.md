# BUG-3599 — Generating an agreement in an unsupported format returns a 500 instead of a 400

## Summary

`POST /contracts/:id/generate/:format` with any format other than `pdf` or
`docx` threw a plain `Error`, which the exception filter reports as a 500
`SYSTEM_UNEXPECTED_ERROR` and records as a system fault.

## Expected Behavior

An unsupported format is a client error: 400 with a catalogued code.

## Actual Behavior

500 `SYSTEM_UNEXPECTED_ERROR`, logged at error severity with a stack trace.

## Reproduction

1. `POST /api/contracts/<id>/generate/html` as a platform admin.
2. Response: 500.

## Evidence

API log, trace `req_fd51d13d-1f19-4be1-9e72-6ee4da3ffbf7`: "Error: Unsupported
document format. at ContractsController.generate (contracts.controller.ts:273)".
After the fix the same request returns 400 `VALIDATION_INVALID_FORMAT`.

## Root Cause

`ContractsController.generate` validated the path segment with
`throw new Error(...)` instead of a Nest `BadRequestException`.

## Impact

Low: no admin screen sends another format, but a crafted request inflates the
error log with false system faults.

## Affected Areas

`services/api/src/modules/contracts/contracts.controller.ts`.

## Proposed Resolution

Throw `BadRequestException` with the existing `VALIDATION_INVALID_FORMAT` code.

## Acceptance Criteria

An unsupported format returns 400 and generates nothing.
