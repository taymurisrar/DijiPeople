# BUG-3905 — Tenant erasure failed on a reference from a record outside the tenant

## Summary

On 2026-08-15 a platform tenant erasure failed with "Tenant erasure failed and
nothing was deleted. A record outside this tenant still references…" (400), and
two `TENANT_ERASURE_FAILED` platform events were emitted. The erasure rolled back
safely. The blocking foreign key was never identified, so the same tenant shape
would fail again. Four later erasures completed.

## Expected Behavior

The erasure plan accounts for every foreign key that can point into a tenant's
rows from outside the tenant, and either detaches or deletes those rows before
the tenant is erased.

## Actual Behavior

One erasure was refused because a reference from outside the tenant was not
handled.

## Reproduction

Not yet reproduced. The blocking reference is unknown. Re-run an erasure on a
copy of a tenant whose shape matches the failing one, and read the constraint
named in the error.

## Evidence

- Production `ErrorLog`, read-only query on 2026-10-07: 1 incident with 2
  occurrences on 2026-08-15, on one tenant. Admin `POST
  /api/platform/tenants/:id/erase` returned 400.
- `PlatformEvent`: `TENANT_ERASURE_FAILED` twice on 2026-08-15. Four later
  erasures completed.

## Root Cause

Not established. The candidate is a platform-side model, such as a support
case, contract or partner link, that references a tenant row and is absent from
the erasure plan.

## Impact

An erasure request for a tenant with that reference cannot complete. This is a
data-protection obligation, but the failure is safe: nothing is deleted.

## Affected Areas

- `services/api/src/modules/tenants` (erasure)
- `services/api/src/modules/tenant-control-plane`

## Proposed Resolution

Identify the constraint from the stored error details, add the referencing model
to the erasure plan, and add a spec that enumerates the cross-tenant foreign keys
into tenant-owned models.

## Acceptance Criteria

- The blocking foreign key is named in this record.
- An erasure of a tenant with that reference completes.
