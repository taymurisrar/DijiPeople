## Summary

Project-allocations export has the same row-scope gap as the employee export, gated by a different permission

Identified by the 2026-09-10 full technical audit as AUTHZ-04 (confidence: AUTHZ-04=CONFIRMED).

## Expected Behavior

Same access check as employee profile reads, since the response is employee-linked data.

## Actual Behavior

No employee-record scoping; tenant-wide by id.
