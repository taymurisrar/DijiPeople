# BUG-4457 — Timesheet late reason is not offered after Save draft, so a late week cannot be submitted

## Summary

After Save draft a late week becomes READY_TO_SUBMIT with its deadline still passed. The editor only offered and sent the late reason while the status was OVERDUE, so the API refused the submission with "A late submission reason is required" and the form gave no way to supply one.


One paragraph: what is wrong, for someone who has never seen this module.

## Expected Behavior

A week past its deadline always offers and sends the late reason.


What the system should do. State it before describing the failure.

## Actual Behavior

The reason field disappears after Save draft; Submit week is refused.


What it does instead.

## Reproduction

1. Fill an overdue week, Save draft. 2. Submit week: 400.


Numbered steps, with the exact request/state. A bug nobody can reproduce is a rumour.

## Evidence

## Root Cause

The editor keyed lateness on status === OVERDUE instead of the deadline.


Why it happens — not the symptom. Leave empty until it is actually established.
