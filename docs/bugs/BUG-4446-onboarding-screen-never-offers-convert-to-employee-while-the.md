# BUG-4446 — Onboarding screen never offers Convert to employee while the linked employee is a draft profile

## Summary

`apps/web/app/(authenticated)/onboarding/[onboardingId]/page.tsx` rendered the Convert to employee button only when the onboarding had no linked employee. "Start onboarding" always creates a draft employee (`createEmployee` defaults to true), so in the flow the product itself starts, the button never appeared. The API converts a draft profile (it refuses only a non-draft employee), so the capability existed but was unreachable from the screen.

## Expected Behavior

With all required tasks complete and Department, Designation and Reporting manager assigned, the screen offers Convert to employee.

## Actual Behavior

The checklist reaches 11 of 11 and the blocking panel clears, but no Convert button is rendered, only Open employee record.

## Reproduction

1. Move an application to HIRED and click Start onboarding.
2. Complete all 11 tasks.
3. Assign department, designation and manager.
4. Open the onboarding screen: no Convert button. `POST /onboarding/:id/convert-to-employee` returns 201 for the same record.

## Evidence

Found by the browser hiring journey (`e2e/tests/flow-o-growth-hiring-browser.spec.ts`, GO-8): an API probe returned 201 while the button was absent. `onboarding.service.ts` refuses conversion only when the employee exists and is not a draft profile.

## Root Cause

The render condition was `!onboarding.employee`, written before Start onboarding created the draft eagerly.

## Impact

An HR user cannot finish onboarding a hired candidate from the UI in the standard flow, which is the closing step of the Growth recruitment demo.

## Affected Areas

apps/web onboarding detail page.

## Proposed Resolution

Render the button when there is no employee or the linked employee is a draft profile; keep the Open employee record link whenever an employee exists. Regression: flow-o GO-8 clicks the button with no API fallback.

## Acceptance Criteria

With a completed checklist and an assigned department, designation and manager, the onboarding screen shows Convert to employee and the conversion succeeds.
