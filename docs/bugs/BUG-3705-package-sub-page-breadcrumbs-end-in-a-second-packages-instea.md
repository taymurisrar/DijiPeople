# BUG-3705 — Package sub-page breadcrumbs end in a second Packages instead of the page

## Summary

On a package detail page and the new Import Package page the breadcrumb reads "Settings / Customization / Packages / Packages". The last crumb repeats the parent instead of naming the page.

## Expected Behavior

The last crumb names the page (the package name, or "Import").

## Actual Behavior

A second "Packages".

## Reproduction

Open any package, or /settings/customization/packages/import.

## Evidence

TASK-0033 browser pass screenshots; the detail page behaved the same before TASK-0033.

## Root Cause

The settings breadcrumb resolves unknown sub-paths to the nearest registered item.

## Impact

Cosmetic.

## Affected Areas

apps/web settings shell breadcrumbs.

## Proposed Resolution

Let a page supply its final crumb.

## Acceptance Criteria

The final crumb is the page's own title.
