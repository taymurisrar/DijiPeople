# BUG-4439 — Admin dashboard cards fail WCAG color-contrast (serious) in the browser accessibility sweep

## Summary

The platform admin dashboard fails the axe color-contrast rule (serious) on the stat cards: slate-400 text on a light surface.

## Expected Behavior

Flow E E3 passes with no serious or critical violations.

## Actual Behavior

Flow E E3 fails on `.p-5 > .mt-3.text-slate-400` and similar nodes.

## Reproduction

Run `npx playwright test tests/flow-e-accessibility-and-layout.spec.ts` against a seeded admin.

## Evidence

Playwright report 2026-11-19 (local), 1 failure of 57.

## Root Cause

Low-contrast utility classes on the dashboard cards.

## Impact

Low: readability of secondary figures for low-vision operators.

## Affected Areas

apps/admin dashboard cards.

## Proposed Resolution

Raise the text colour to a token that meets 4.5:1.
