## Why Render staying quiet is correct, not a missed deploy

The API reports `2609275`, which is two releases old. That reads like a failed
deploy and is not one — the same reasoning as release `08d7901`, checked again
here rather than carried over on trust.

Render's service has `rootDir: services/api`. Measured from the **deployed**
commit to this release, not merely from the previous `main`:

```
git diff --name-only 2609275..b94c1321 -- services/api            → 0 files
git diff --name-only 2609275..b94c1321 -- packages render.yaml    → 0 files
```

Nothing Render builds has changed since the commit it is serving, so there was
nothing to rebuild. A deploy here would have produced an identical artefact.

**This distinction is worth re-deriving every time.** "The served commit is
behind `main`" is the signature of both a correct no-op and a silently failed
deploy, and only the diff tells them apart.

## What this release actually contains

An **agent-framework release**. It changes how agents work in this repository,
not what the product does:

- **Browser control** — `.mcp.json` declares `@playwright/mcp`, so an agent can
  navigate, click, snapshot and read console and network output on the running
  product. Verified by speaking MCP to the committed config: 24 tools.
- **Component knowledge** — `.agent/context/component-index.md`, generated from
  the doc-comments above exported components, stamped with its own provenance
  and checked for drift in CI.
- **Retrieval that finds it** — `command-bar`, `command bar` and
  `ModuleActionBar` now reach the same documents. Before, one hyphen was the
  difference between the answer and silence.
- **A UI review procedure** — `.agent/skills/ui-review.md`, which requires the
  contract to be retrieved and the prediction written down *before* the browser
  opens.

Three framework defects were found by that work's own verification and fixed in
the same chain: [[BUG-1203]] and [[ITEM-0091]] (both in `MAIN_CHANGE_STATUS`,
the field that reports an unauthorised mutation of this very branch), and
[[BUG-1208]] (a drift check that failed on every Windows checkout and passed in
CI).
