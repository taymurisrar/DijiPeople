# LESSON-0001 — Pin the repo npm major in CI, not the runner default

## Evidence

Run 40198343104 (`dependabot/.../electron-42.11.16`): `EBADENGINE required npm 11.x, current npm 10.9.9` then `npm error code EUSAGE`, failing 14 jobs. `develop` passes because its lockfile was written by npm 11.

## Proposed change

Composite setup action that pins `npm@11`; add `.github/dependabot.yml`. Rule: CI installs with the engines-declared npm (see docs/engineering/ci-reliability.md R-2).

## Why this is not already covered

`engines` only warns (EBADENGINE); nothing fails on the mismatch itself. `scripts/preflight.mjs` covers local runs only.
